Outside of web dev, I run paid tabletop RPG sessions online, mostly Call of Cthulhu, through stillplaying.games on StartPlaying.games. 200+ paid sessions run so far.
Running that many games exposed a lot of rough edges in the tools GMs use, so I've built a handful of FoundryVTT add-ons to smooth out real sessions: character sheets, dice-roll requests, and PDF importers. See the Portfolio section above for those.
